# CAMPUS

CAMPUS is an academic and career skill development platform designed to connect students, faculty, colleges, and companies.

## Features

- Student profile and skill analysis
- Aptitude and real-problem-based skill assessment
- Job-role based skill gap identification
- Learning resource recommendations
- Faculty and college dashboards
- Company internship and vacancy notifications
- Skill-gap based workshops and seminars

## User Roles

- Student
- Faculty
- College
- Company

## Project Structure

- `frontend/` – Frontend components for students, faculty, companies, and colleges
- `backend/` – Backend functions and database connection
- `database/` – Database migration files

## Technologies

- Frontend: TypeScript / TSX
- Backend: TypeScript
- Database: SQL
- AI: Recommendation and skill-analysis component
